# Resume Analyzer AI 🚀

This is an AI-based Resume Analyzer that checks your skills and suggests improvements.

## 🔹 Features
- Detects skills from resume
- Finds missing skills
- Gives resume score
- Suggests improvements

## 🔹 Tech Used
- Python
- Google Colab

## 🔹 Output Example
- Resume Score: 50%
- Missing Skills: SQL, Machine Learning, Data Analysis

## 🔹 Future Improvements
- PDF Resume Upload
- Web Interface
- Advanced AI (NLP)
